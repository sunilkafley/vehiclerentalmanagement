# Vehicle Rental Management System

A web-based Vehicle Rental Management System developed using JavaScript and the MVC (Model-View-Controller) architecture pattern.

## Features

- Manage vehicle records
- View available rental vehicles
- Add, update, and delete vehicle information
- User-friendly interface
- Organized MVC project structure

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- MVC Architecture
